# Application Météo Python

Une application météo avec interface graphique développée en Python.

## 🚀 Fonctionnalités
- Affichage de la météo en temps réel.
- Interface utilisateur simple et intuitive.

## 🛠️ Technologies utilisées
- **Langage :** Python
- **Interface graphique :** Tkinter (ou CustomTkinter / PyQt)
- **API Météo :** OpenWeatherMap (ou l'API que vous avez utilisée)
